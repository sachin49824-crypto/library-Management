Library Management System

A Java-based **Library Management System** that simplifies and automates the daily operations of a library. This console-based application allows users to manage books, members, book issuing, and returns efficiently using object-oriented programming concepts.

 Abstract

The Library Management System is a Java application developed to automate and simplify library operations. It enables users to manage book records, member information, book issuing, and returns while maintaining data efficiently. The project follows Object-Oriented Programming (OOP) principles to create a modular and maintainable system. It reduces manual effort, improves accuracy, and serves as a practical learning project for Java programming.



 Features

*Add new books
*Update book details
*Delete books
*Search books by ID or title
*Add and manage library members
*Issue books to members
*Return issued books
*Display all available books
*  Console-based menu-driven interface

How to Run

1. Clone the repository.

```bash
git clone https://github.com/your-username/LibraryManagementSystem.git
```

2. Open the project in your preferred Java IDE.

3. Compile the Java files.

```bash
javac *.java
```

4. Run the application.

```bash
java Main
